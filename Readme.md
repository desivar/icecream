🍦 Scoops & Smiles Dashboard & Smart Inventory
A delightful, kid-friendly ice cream shop management system featuring an aesthetic pastel rainbow interface and an AI-driven inventory automation backend.
![Portfolio Screenshot]() 

✨ Features
🎨 Aesthetic Pastel Dashboard: Designed with a cheerful "pastel rainbow" color scheme and smooth micro-interactions tailored for an engaging experience.

📦 Real-Time Inventory Tracking: Monitors stock levels for ice cream flavors, cones, toppings, and ingredients dynamically.

🤖 AI Predictive Restocking: Analyzes sales trends and weather patterns to predict when ingredients will run out before they hit zero.

📱 Automated Provider Alerts: Automatically dispatches alerts or purchase orders to suppliers when stock reaches critical thresholds.

👥 Role-Based Management: Intuitive controls for shop admins to manage products, view sales reports, and track supplier communications.

🛠️ Tech Stack
Frontend:

HTML5, JavaScript

Tailwind CSS (via CDN) for rapid prototyping and custom pastel theme styling.

Backend:

Apache Groovy running on the Java Virtual Machine (JVM).

Spring Boot / Grails framework for robust REST APIs and database integration.

Database:

PostgreSQL / MongoDB managed via GORM / ORM.

AI Integration:

Automated predictive triggers connected via backend service hooks.

💡 Project Inspiration
This project bridges the gap between playful, user-centric frontend design and robust JVM backend architecture, incorporating modern AI automation to solve real-world small business inventory challenges.
